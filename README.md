## 사용

필요한 스킬의 SKILL.md부터 읽고, 해당 작업에 필요한 보조 자료만 확인합니다. 공통 참조가 있으므로 skills/의 폴더 구조를 유지하세요. GitHub 보관과 로컬 설치·외부 서비스 연결은 별개입니다.

개인 문서·공부 기록·계정 정보·캐시·로그는 저장하지 않습니다. 외부 유래 스킬의 라이선스와 upstream-lock.json을 보존합니다. 실제 토큰 절감률은 측정 전까지 미확인입니다.
