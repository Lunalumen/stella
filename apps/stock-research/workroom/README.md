# Stock Workroom

A Windows-only local UI prototype illustrating a research team's workflow. Launch from this directory with `powershell -NoProfile -File start.ps1`; it uses loopback port 8767, an explicit asset allowlist, an account-protected launch key and authenticated session cookies. Use `stop.ps1` to stop the matching process. Authentication state and logs are generated under the parent `private/` folder, which is excluded from Git.

The characters and meetings are scripted animation, not active AI agents. The SCHD section is an explicitly dated saved public-source example (2026-11-02), not a fresh response to the entered ticker or a current investment recommendation. No personal trading/account data is included. Optional TradingView chart loading contacts that third party and is subject to its availability and terms; it is not a broker connection or verified real-time market feed.

The original generated background image is excluded from this source export; a CSS gradient is used instead. No actual research results or launch keys are copied. The exported server/launcher requires fresh local Windows runtime verification before relying on it.
