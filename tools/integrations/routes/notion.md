# Notion
현재 연결된 hosted Notion 플러그인을 기본으로 쓴다. 지정한 페이지 또는 짧은 검색 → 필요한 원문 순서로 읽는다. 이번 연결 도입은 새 데이터베이스·페이지·공유 설정을 만들지 않는다. 저장 요청이 있을 때만 대상·내용을 확인해 반영한다. 주식 자료의 자동 저장 대상이 아니다.
`../upstream/notion`의 MIT 공개 로컬 서버는 더 이상 적극 유지보수되지 않는다. 사용자용 수정·테스트 참고본으로 보존한다. 로컬 실행과 도구 목록 확인이 성공해도 Notion 인증·실제 페이지 접근 성공을 뜻하지 않는다. 실제 로그인 없는 결과를 연결 완료로 표시하지 않는다.
