# Integration Router

Select the smallest relevant integration branch without loading every service. `python luna.py route "GitHub repository"` chooses routing metadata; `python luna.py status` reports local configuration. A route result is not a completed external request or proof of live authentication. Stock routing points to the program and canonical skill in this repository.

Existing connected host plugins are the default service path. The source includes optional, explicitly invoked setup scripts only: `bootstrap.py` retrieves sparse upstream checkouts and writes its local revision lock without running upstream setup instructions; `install-runtime.py` downloads pinned local runtime dependencies; `check-runtime.py` checks stdio readiness without calling service tools; `local-server.py` launches a configured local MCP. No installer or network check was run for this export.

Install Git, Python 3.12+, and Node.js yourself as needed. `NODE_EXE` selects a Node executable; otherwise PATH is used. Platform-specific installers target Windows. Generated `runtime/`, `upstream/`, `private/` credentials, and install/connector logs are ignored and not bundled. Do not assume service fees, API keys, card requirements or free quotas from the presence of free source code: confirm the selected provider's current official conditions before enabling it. This export adds no subscription or payment.

The registry links upstream GitHub MCP, Google Workspace MCP, Firecrawl, Context7 and Notion projects with their own licenses. No full upstream server source or prebuilt runtime is republished here. Self-hosting Firecrawl is not implemented by the router and requires separate service setup. No new connector permissions or automatic watchers are enabled.
