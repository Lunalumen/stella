# Stella kb-retriever

사용자가 지정한 자료 목록·색인에서 관련 파일부터 고른다. 전체 폴더를 자동 수집하지 않는다. 키워드 검색 → 주변 문맥 확인 → 부족할 때만 범위 확대 순으로 읽는다. 저장본은 변경 여부를 확인해 재사용한다. PDF는 페이지, PPT는 슬라이드, 문서는 절 위치를 남긴다.

## 짧고 정확한 입력 만들기

사용자가 원하는 작업·산출물·독자를 먼저 파악한다. 관련 정보만 선택하고 반복 설명·인사·중복 예시는 줄인다. 목표, 필수 조건, 금지 사항, 숫자·단위·날짜, 예외, 결정 사항, 미해결 질문과 출처는 보존한다. 인용문·코드·계약 문구처럼 정확한 표현이 중요한 내용은 임의로 바꾸지 않는다. 서로 충돌하는 조건은 숨기지 않는다.

기본 출력은 복사해서 쓸 수 있는 간결한 프롬프트다. 필요할 때만 목표 / 핵심 정보 / 조건 / 원하는 결과로 나눈다. 자료 전체 요약 요청은 일부 검색 결과로 대체하지 않는다. 부족한 정보는 미확인으로 남기며 추측으로 채우지 않는다.

압축 전후 중요한 조건이 남았는지 대조한다. 재설명이나 재시도를 포함한 실제 사용량을 측정하기 전에는 토큰 절감률을 주장하지 않는다. 요약 생성 자체의 처리 비용도 고려한다.

## 선택형 원본 참고

원본은 references/upstream/에 보존했다. 현재 작업에서 필요한 구간만 참고하고 원본의 설치·전체 색인·외부 호출 지시를 자동 실행하지 않는다. 이 스킬은 외부 런타임 설치나 연결 완료를 뜻하지 않는다.
