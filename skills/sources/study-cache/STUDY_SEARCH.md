# 개인 공부 검색 개선

공부 검색을 먼저 개선하고 업무 자료 확장은 다음 단계로 둔다. 유료 API·모델·새 의존성을 추가하지 않았다.

| 합성 비교 항목 | 기존 | 개선 |
|---|---|---|
| 이진탐색 질문 / 이진 탐색 본문 | 검색 실패 | 검색 성공 |
| 정렬 비교 질문 / 정렬만 100회 반복한 자료 | 반복 자료 1위 | 두 단어가 함께 나오는 자료 1위 |
| 예외가 다음 PDF 페이지에 있는 경우 | 별도 수동 조회 | 선택형 앞뒤 문맥으로 회수 |

--context-sections 1 --max-total-chars 3600을 search에 추가한다. 기본 앞뒤 문맥은 0으로 유지해 불필요한 출력을 피한다. 제한은 본문 문자 수이며 실제 토큰·총사용량이 아니다. 앞뒤 문맥도 미검증 원문이며 정답·출제 근거로 자동 확정하지 않는다.

scripts/verify_study_search.py로 재현 가능하다. 테스트용 reportlab과 PDF용 pypdf가 필요하다. 생성한 한글 TXT와 영문 PDF만 사용한다. API 키 환경변수 제거·네트워크 차단 후 검색·예외 문맥·분량 제한·과목 분리·캐시 재사용·변경 파일 차단 등 7개 검사 통과. 기존 캐시 7개 검사와 설치된 래퍼 실행·스킬 형식 검증도 통과했다.

정확도 변화는 작은 합성 예제에서만 확인했다. 실제 강의·OCR·동의어·표·그림·수식·모델 답변·토큰 절감률·대규모 속도는 미검증이다. 모든 자료를 미리 등록하지 않으며 사용자 지정 자료로 다음에 평가한다.
