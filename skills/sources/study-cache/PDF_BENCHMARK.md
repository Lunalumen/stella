# PDF 캐시 비교 실험

## 확인 결과

생성한 영문 텍스트 PDF 20쪽에서 두 질의를 검색했다. 사용자 자료·모델 API는 사용하지 않았다.

| 질의 | 전체 추출 텍스트 | 선택한 본문 | 검색 응답 JSON 전체 | 필수 사실 보존 |
|---|---:|---:|---:|---:|
| ALPHA | 24,913자 | 94자 | 566자 | 3/3 |
| BETA | 24,913자 | 50자 | 523자 | 2/2 |

JSON 길이는 임시 경로 길이에 따라 달라진다. 비교 단위는 문자이며 토큰 수가 아니다. 두 질의의 필수 사실을 회수하는 추가 조회는 0회였다. 별도 10자 제한 실험에서는 예외 조건이 잘려 페이지 전체 추가 조회가 필요했다.

페이지 보존, 재추출 건너뛰기, 빈 페이지 경고, 두 질의의 필수 사실과 위치, 잘린 발췌 확대, 검색 실패, 변경 파일 차단, 빈 PDF 실패 시 캐시 보존, 새 PDF 재등록의 9개 검사를 통과했다.

## 재현

pypdf와 reportlab이 있는 Python 환경에서 scripts/verify_pdf_cache.py를 실행한다. 샘플·DB는 임시로 만들고 정리한다. reportlab은 실험용이며 일반 캐시에는 필요하지 않다. --output으로 개인 검증 기록을 저장할 수 있다.

## 한계

이 결과는 반복 배경이 많은 합성 PDF에서 키워드와 미리 지정한 필수 사실을 회수한 작은 실험이다. 일반 PDF 검색 정확도, 한국어, OCR, 표·수식·그림, 실제 모델 답변 품질·재질문 횟수·총토큰·비용은 검증하지 않았다. 스킬 기본 검증기는 실행 환경에 PyYAML이 없어 완료하지 못했다. 진입점 필수 필드와 로컬 링크는 별도 검사했다. 원본 보관용 upstream 문서의 링크는 수정하지 않았다.

## 운영 변경

세 Stella 검색·탐색·변환 진입점의 반복 프롬프트 규칙을 제거했다. 프롬프트 작성 요청일 때만 stella-concise-prompt로 연결한다. PDF는 pypdf로 물리 페이지별 저장하며 시각 요소는 미검증으로 표시한다. 외부 설치·원자료 수집·OCR은 자동 실행하지 않는다.
