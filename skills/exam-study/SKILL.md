# 공부 목적에 맞게 선택하기

[자료 판단 공통 원칙](../read-and-summarize/references/source-rules.md)을 읽고 자료를 실제로 확인한다. 불필요하게 최상위 스킬과 모든 하위 스킬을 연쇄 호출하지 않는다.

- 코드 추적·작성·알고리즘 풀이: [study-algorithms](../study-algorithms/SKILL.md)
- 단답형·서술형·미학 답안: [study-essay](../study-essay/SKILL.md)
- 역사 인과·시대 흐름·동시대 비교: [study-history](../study-history/SKILL.md)
- 시험까지 공부 시간·복습 배분: [study-plan](../study-plan/SKILL.md)

한 작업은 가장 맞는 스킬부터 시작한다. 역사 서술형처럼 두 기능이 필요할 때만 두 개를 조합한다. 계획이 필요하지 않은 문제 풀이에 계획 스킬을 자동으로 붙이지 않는다.

공통 학습 방식:
- 자료 수집 중에는 확인·등록만 하고 사용자의 시작 요청 전에 대량 수업을 시작하지 않는다. 전부 제출하지 못해도 확인 자료부터 진행한다.
- 과목·시험일·범위·유형·하루 시간·약점은 아는 것만 기록하고 나머지는 미확인으로 둔다. 한 번에 질문은 세 개 이하.
- 짧은 목표·복습 → 핵심 설명 → 한 문제 → 학생 답 확인 → 채점·필요한 설명. 정답·풀이를 요청하면 바로 공개하고, 직접 풀 문제의 정답은 먼저 보여주지 않는다.
- 오류는 개념 부족·암기 부족·문제 해석·계산 또는 코딩 실수로 구분한다. 출처·문항·오류 원인·다음 복습만 간결하게 기록하며 문제 풀이 전 자료 준비를 학습 완료로 처리하지 않는다.
- 사용자가 지정한 현재 공부 기록 또는 로컬 references/local-context.md가 있으면 필요한 구간만 참조한다. 기록이 없으면 대화에서 관리한다. 개인 기록을 GitHub에 올리지 않는다.
