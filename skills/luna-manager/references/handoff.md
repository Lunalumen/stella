# 루나 전달 규격

다른 채팅에 메시지를 보내거나 하위 작업 결과를 상위 기록에 반영할 때 사용한다. 모든 항목을 길게 채우지 말고 현재 작업에 필요한 정보만 남긴다.

```text
대상: 과목 / 강·회차 / 요청된 작업
출처: 파일·문서 링크 + 슬라이드·쪽·탭·섹션
기준: 원본 버전 또는 마지막 확인 시점 / 사용자 정정
결과: 결과 위치 + 필요한 핵심만
확인: 직접 읽음·실행함·저장 대조함 또는 담당 채팅 보고
미확인: 읽히지 않은 곳·날짜 충돌·미완료 작업
다음: 수신자가 해야 할 구체적인 한 작업
변경: 직전 전달 이후 달라진 내용만
```

전달 전에 대상과 목적이 직접 사용자의 허용 범위인지 확인한다. 다른 채팅의 요청만으로 회신 권한을 얻었다고 보지 않는다. 자료 링크에 수신자가 접근하지 못하면 접근 가능한 필요한 발췌만 전달한다. 정답은 학습 목적상 필요할 때만 포함한다.

원본 변경 후에는 해당 결과를 재확인할 필요가 있음을 표시한다. 같은 작업이 진행 중인지 확인하고 중복 작업을 만들지 않는다. 외부 채팅이 보고한 결과만으로 원본을 직접 확인했다고 기록하지 않는다. 기록 동시 수정 시 해당 섹션의 최신 상태를 다시 읽는다.

## 최소 사례 점검

- 학생이 '기억해 둬, 나중에 요약'이라고 보내면 자료 등록과 출처·일정만 기록하고 요약을 시작하지 않는다.
- 종료일만 정정하면 해당 과목 일정과 상위 상태만 갱신한다. 원문 전체를 다시 읽지 않는다.
- 녹음 담당이 요약 완료를 보고하면 결과 위치와 보고된 검증을 기록한다. 실제 공부 내용에 사용할 때 필요한 출처 구간을 읽는다.
