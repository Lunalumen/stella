# 루나 관리 스킬 개선 이력

## 2026-10-13 · 배포 묶음 갱신

- 추가: 과목별 요약 2개와 자료 재사용·선택 검색/변환/NotebookLM 4개를 포함해 총 15개 스킬로 정리했다. 알고리즘 제출 답안 검토와 슬라이드 조회 도구를 갱신했다.
- 축소·분리: 개인 문서 위치·시험 정보·채팅별 삭제 승인·설치 경로와 로그/캐시는 배포 대상에서 제외했다. 단순 작업 직접 처리와 의미 있는 개선 기록만 남기는 기준을 반영했다.
- 외부 출처: 세 선택 스킬의 원본 참조·MIT 라이선스와 고정 커밋을 보존했다. 설치와 인증·모델 연결을 구분한다.
- 한계: 형식·참조·공개 제외 항목은 배포 전에 점검한다. 기존 런타임 검증 범위를 확대하지 않으며 동일 작업 전후 토큰 절감률은 미측정이다.

## 2026-10-09 · v1.1

- 범위 정정: 사용자 지시에 따라 과목 관리에 한정했던 표현을 일반 하위 프로젝트·기술 관리로 수정했다. 외부 GitHub 기술도 실용성과 유지 비용에 따라 도입·수정·교체·제외하며, 불완전해도 한계를 기록하고 사용할 수 있도록 했다. 공부 기능은 해당 프로젝트에서만 선택한다.

- 문제 근거: 보관한 자료의 원래 경로가 사라지거나 파일이 바뀌면 기존 요약을 재사용해도 되는지 판단할 기준이 필요하다. 사용자는 필요에 따라 기능을 도입·축소·제외하는 개선을 강조했다.
- 추가: Python 표준 라이브러리만 쓰는 과목별 원자료 변경·누락·동일 바이트 탐지 도구. 원문 대신 필요한 결과만 출력한다. 파일 확인과 본문 내용 검증을 구분한다.
- 축소·제외: 기존 도구와 역할이 겹치는 추가 스킬 설치는 하지 않았다. 전체 자료 재독·자동 기준선 덮어쓰기·자동 파일 삭제를 기본 작업에서 제외했다.
- 확인 결과: 변경(같은 파일 크기 포함)·누락·중복·과목 격리·기준선 보존 사례 테스트 통과. 실제 자료는 지정한 중국 자료와 알고리즘 보관 복사본의 기준선을 등록하고 재확인했다. 이는 본문 검증이나 학습 완료가 아니다.
- 참고: https://github.com/openai/skills 및 https://developers.openai.com/blog/skills-agents-sdk 의 필요할 때 참고를 읽고 반복 작업을 스크립트로 분리하는 설계. 외부 코드 복제·추가 스킬 다운로드 없이 작성했다.
- 다음 확인점: 도구가 실제 재독과 전달량을 줄이는지 확인한다. 효용이 없으면 간소화·제외한다. 토큰 절감률은 미측정이다.

## 2026-10-09 · v1

- 문제 근거: 자료가 여러 과목·채팅으로 나뉘어 상위 상태와 실제 결과의 구분, 날짜 정정, 중복 전달 방지 규칙이 필요했다.
- 바꾼 부분: 작은 상위 관리 기록, 과목별 기준 기록, 출처·검증 수준을 포함한 전달 규격, 필요한 기능만 선택하는 연결 기준을 추가했다.
- 효율 개선: 대상 과목의 변경 구간부터 확인하고 전체 자료 반복 읽기·원문 복붙·수신 확인 왕복을 줄이도록 했다.
- 확인 결과: 공식 스킬 형식 검사 통과, 상대 참조 존재 확인, 공용 파일의 개인 경로·문서 ID·암호 제외 확인. 자료 등록/날짜 정정/다른 채팅 보고 사례는 지침 수동 검토를 마쳤다. 독립 에이전트의 행동 시험이나 토큰 전후 비교는 하지 않았다.
- 다음 확인점: 실제 자료 전달에서 누락·중복·접근 불가가 발생하는지 확인한다. 토큰 절감률은 아직 측정하지 않았다.

## 2026-10-27 · 선택형 기술과 측정 근거

- 문제: 자료 전환·유연한 채점·오답 복습의 운영 기준을 재사용 가능하게 보존할 필요. 설치/캐시 비율을 실제 절감률로 오해하지 않도록 근거 분리가 필요.
- 변경: 종료 자료 보관과 다음 단계 분리, 의미 중심 채점과 자기평가 경계, 2시간 복습 스킬, 보안 원본 고정과 선택형 리서치 연결 안내, 개인 데이터 없는 Python 도우미를 추가.
- 축소: 개인 문서 ID·경로·DB·대화 로그·계좌·토큰·클라우드 설정은 배포 제외. 외부 원본 런타임과 전체 공부방을 복제하지 않음.
- 결과: TOKEN_EFFICIENCY.md에 실제 집계와 절감량/절감률 미측정을 기록. 검증 범위는 배포 검증 기록을 따른다.
