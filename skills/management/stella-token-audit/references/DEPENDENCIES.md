# 의존성과 검증

usage 모드는 Python 표준 라이브러리만 사용한다. text 모드는 MIT tiktoken 0.14.0과 명시적으로 준비한 토큰 사전을 사용해 검증했다. 기본 실행은 자동 네트워크 다운로드를 막는다. 새 환경에서는 별도 준비가 필요하다. 의존 바이너리와 사전은 저장소에 포함하지 않는다.

공식 출처 https://github.com/openai/tiktoken — 설치 패키지에 포함된 라이선스를 유지한다. 외부 코드를 복사하지 않고 라이브러리를 호출한다.

합성 usage에 대한 8개 단위 검사와 토크나이저의 오프라인 5개 검사, 설치된 명령 실행·공식 스킬 형식 검사를 통과했다. 실제 전체 작업 로그로 유료 사용량 절감을 입증한 것은 아니다. 테스트 성공과 평가 대상 스킬의 절감 성공을 구분한다.
