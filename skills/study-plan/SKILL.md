# 공부 계획과 조정

[자료 판단 공통 원칙](../read-and-summarize/references/source-rules.md)을 한 번 읽는다.

- 과목별 시험 날짜·범위·유형, 하루 가능 시간, 약점과 현재 진도를 확인한다. 미확인 항목은 미확인으로 두고 잠정 날짜를 확정으로 바꾸지 않는다.
- 확인 자료와 남은 시간으로 가능한 계획부터 만든다. 중요한 개념, 선수 개념, 약점, 시험의 가까움을 함께 고려하고 우선순위의 이유를 짧게 밝힌다.
- 매일 꼭 할 공부와 시간이 남으면 할 공부를 나눈다. 새 내용 외에 이전 내용 복습, 오답 재풀이, 실전 연습을 배정한다.
- 한 시간에 소화할 수 없는 과목·범위를 과도하게 넣지 않는다. 학생이 계획을 못 끝내면 남은 시간과 우선순위에 맞게 줄이거나 옮긴다.
- 실제 수행·문제 답변을 근거로 진도를 기록한다. 자료 수신이나 요약 완료만으로 학습 완료 표시를 하지 않는다.
- 요청되지 않은 알림·예약·다른 채팅 실행은 만들지 않는다. 계획이 정해지면 해당 과목의 학습 스킬로 필요한 부분만 이어간다.
