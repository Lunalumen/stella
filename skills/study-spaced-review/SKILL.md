# 오답을 나중에 다시 풀기

- 제출·채점된 본인 기록에서 오답·부분 정답을 등록하고 이후 정답도 이전 오답 이력과 연결한다. 미응답·검토 보류 서술형은 확정 오답이 아니다.
- 과목·범위·원문 문항·근거 위치를 보존한다. 같은 문항 재풀이는 독립 문항으로 세지 않는다. 요청 범위 밖의 자료·유형을 추가하지 않는다.
- 시험기간 복습 간격은 정답·오답 모두 마지막 채점 제출 시각부터 2시간이다. 한 번 틀린 문항은 이후 맞혀도 목록에 유지한다. 기존의 일 단위 간격을 사용하지 않는다. 시험 완료 과목은 예정 복습에서 제외하고 기록은 보존한다. 개인용 설정이며 최적 효과를 보장하지 않는다.
- 한국 시간의 제출 시각을 사용한다. 제출일이 없는 과거 기록은 생성 시각 대체라고 표시한다. 예정일과 근거를 기록하되 학습 완료로 단정하지 않는다.
- 재풀이에서는 이전 답안·정답·해설을 숨기고 전체 제출 후 채점한다. 정답 요청에는 바로 응한다. 원인은 풀이/자기평가에 근거하고 모르면 미확인이다.
- 기록 삭제 시 복습 목록도 없어진다. 자동 알림·채팅 동기화·예약 실행을 만들지 않는다.

연결 예시는 references/study-engine/README.md를 확인한다. 스킬 자체가 사이트 실행 엔진이나 알림 서비스는 아니다. 제공 도우미는 등록 문항 재출제용 일정이며 AI 변형 문제 생성이 아니다. 기존 기록을 재사용하고 다른 기기·채팅 동기화는 별도로 구현한다.
