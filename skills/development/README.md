# 개발

- [java-exe-batch](java-exe-batch/SKILL.md): Java 콘솔 예제를 JAR·JSmooth EXE로 일괄 생성하고 실행 결과를 검증합니다. PowerShell 7과 설치된 JDK·JSmooth가 필요합니다.
- [frontend-design](frontend-design/SKILL.md): UI를 만들거나 고칠 때 템플릿 같지 않은 색·글꼴·레이아웃을 정합니다. (Anthropic)
- [mcp-builder](mcp-builder/SKILL.md): Python·TypeScript로 MCP 서버를 설계·구현·평가합니다. (Anthropic)
- [webapp-testing](webapp-testing/SKILL.md): Playwright로 로컬 웹앱을 조작·테스트하고 스크린샷·콘솔 로그를 확인합니다. (Anthropic)
- [doc-coauthoring](doc-coauthoring/SKILL.md): 기술 문서·제안서·스펙을 단계별로 함께 작성합니다. (Anthropic)
