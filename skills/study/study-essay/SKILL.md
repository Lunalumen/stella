# 단답형과 서술형 공부

[자료 판단 공통 원칙](../../sources/read-and-summarize/references/source-rules.md)을 한 번 읽는다. 교수님의 설명·용어를 답안 기준으로 삼고 일반 해석과 차이가 있으면 표시한다.

- 단답형: 정의·구별점·사례에서 핵심 용어를 떠올리는 문제 하나를 낸다.
- 서술형: 문제의 요구(설명·비교·평가·원인 등)를 먼저 파악하고 주장 → 근거 → 사례로 쓰게 한다. 아직 제출하지 않은 답안의 모범 답안을 먼저 공개하지 않는다.
- 비교형: 같은 비교 기준에서 두 개념·인물을 설명하고 공통점과 차이점을 구분한다. 서로 다른 질문에 답한 두 설명을 비교라고 처리하지 않는다.
- 채점: 핵심 개념, 논리적 연결, 자료에 근거한 설명·사례, 빠진 조건을 확인한다. 공식 배점표가 없으면 임의 점수를 공식 성적처럼 제시하지 않는다.
- 오류 원인을 개념/암기/문제 해석/계산·코딩 실수 중 맞는 항목으로 분류하고, 답안 전체 재작성보다 우선 필요한 문장·연결을 고치는 연습을 제시한다.
- 미학: 작품 평가의 기준, 철학자의 존재·인식·윤리 관점과 용어를 수업에 맞춰 연결한다. 같은 철학자의 서로 다른 논의나 시기 차이를 지우지 않는다.

역사 흐름까지 필요한 서술형이면 study-history를 그때만 함께 읽는다.

## 표현과 핵심 의미를 구분하는 채점

모범 답안의 문장 일치보다 핵심 개념·논리·근거·조건 충족을 본다. 단답형의 등록 인정 표현과 제한된 종결 표현은 허용할 수 있지만 새로운 동의어나 부정·모순을 키워드 개수로 판정하지 않는다. 자동 판단이 어려우면 검토 필요로 남긴다. 자기채점은 기준별 점수와 이유·확인 여부를 남기고 사용자 자기평가/예상 점수로 표시한다. 최초 자동 채점과 답안은 보존한다. 의미 채점 모델의 실제 연결과 로컬 규칙을 구분한다.
