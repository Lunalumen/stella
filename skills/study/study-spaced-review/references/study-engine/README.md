# 로컬 공부 도우미 예시

실제 수업 자료·정답·DB·화면·API 키를 제외한 Python 표준 라이브러리 도우미다. 원래 공부방 전체 애플리케이션이나 즉시 실행 가능한 사이트를 포함하지 않는다.

- `flexible_grading.py`: 호출자가 제공한 정규화 함수와 정답/등록 인정 표현을 사용한다. 제한된 정답 제시 문장 틀만 허용한다. 부정·긴 설명·추가 주장에 핵심 용어가 들어가면 review로 남긴다. AI 의미 채점이 아니다.
- `weakness.py`: 과목/문항/출처와 연결된 제출 결과를 개념별로 묶는다. 자동 태그는 확인 필요다. 같은 개념 문항의 반복을 독립 증거로 늘리지 않는다. 제공된 개념 규칙은 예시이며 사용자 자료에 맞게 검토한다.
- `spaced_review.py`: 오답 이력이 있는 문항을 마지막 평가 제출부터 2시간 뒤로 예약한다. 이후 정답도 목록에 남긴다. 간격은 개인용 설정 예시이며 최적 효과를 보장하지 않는다. 완료 과목 집합은 빈 상태로 배포하고 로컬에서 지정한다. 중간/기말 등 시험 식별자는 기록의 `exam`에 둔다. 알림이나 DB 저장은 제공하지 않는다.

## 연결 계약

`records`는 `id`, `created`, `course`, JSON 문자열 `payload`와 `result`를 가진 사전 목록이다. payload는 `exam`, `scopes`, `questions`를 포함하고, 각 문항은 `id`, `type`, `topic`(없으면 지문으로 식별), `source_ids`, `prompt` 등을 가진다. result는 `submittedAt`과 `rows`를 포함한다. 각 결과 행은 `id`, `status`, `needsReview` 등을 가진다. courses는 과목 ID에서 name 등으로 연결되는 사전이다.

호출자가 제출 완료와 기록 소유권을 검증한 뒤 해당 사용자 기록만 전달해야 한다. 도우미는 인증이나 안전한 HTTP 서버를 구현하지 않는다. 재출제용 비공개 문항에는 정답이 있을 수 있으므로 브라우저 응답은 id/type/points/prompt/options 같은 명시적 허용 목록으로 별도 구성하고 제출 전에 정답·해설·이전 답안을 전송하지 않는다. `report` 출력과 비공개 재출제 데이터를 혼동하지 않는다.

기존 기록에 제출 시각이 없으면 생성 시각 대체임을 표시한다. 검토 보류·미응답·OX를 확정 오답으로 넣지 않는다. 현재 예시의 자동 관찰 규칙은 진단 도구나 공식 성적 산출이 아니다. 코드형 등 추가 유형은 실제 채점 계약에 맞춰 별도 확장해야 한다.

## 자료와 기록 분리 원칙

시험마다 원문 저장본·문제은행에 시험 ID를 명시한다. 기존 자료를 다른 시험으로 바꾸어 부르지 않는다. 범위가 누적된다고 확인되면 출처 재사용을 명시해 등록한다. 종료 시험도 과목 목록·기록·회고에는 남기고 예정 복습에서만 제외한다. 원본 이동 대신 링크/고정 보관본으로 기존 참조를 보존한다. 별도 DB 백업은 운영 기록 삭제와 별도로 관리된다고 안내한다.

자기채점은 핵심 개념·논리·근거의 기준별 점수와 인정/감점 이유를 남기고 자기평가·예상 점수라고 표시한다. 최초 자동 채점 결과도 보존한다. 키워드 개수로 의미를 판단하지 않는다.
