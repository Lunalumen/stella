# 녹음 대본을 읽고 흐름 정리하기

[자료 판단 공통 원칙](../read-and-summarize/references/source-rules.md)을 한 번 읽는다. 원음 전사가 아니라 이미 제공된 대본의 정리 작업이다.

- 대상 문서·탭·회차·출력 위치와 사용자의 개인 필기를 확인한다. 개인 필기는 중요 주제 대조용이며 별도 수정·재요약하지 않는다.
- 잡담·반복·정치적 비유·개인 평가를 덜고 비유가 설명하려는 역사·정치 개념과 관계를 남긴다.
- 전체 흐름 먼저 → 단계별로 이어지는 이유와 핵심 개념 → 다음 회차 연결 순으로 정리한다. 사용자가 짧게 다루라고 한 회차는 압축하되 중요한 개념을 누락하지 않는다.
- 전사 오류는 필기·문맥으로 대조한다. 확실하지 않은 인명·연도·수치는 확인 필요로 표시하고 숫자를 임의 보정하지 않는다.
- 병행 흐름, 시간 되돌림, 후대 비교를 구분한다. 필기의 뒤 회차 내용을 앞 대본에 임의로 넣지 않는다.
- 회차 정정·중복 통합은 지정 범위에만 반영한다. 여러 AI 요약 간 충돌은 원문·필기와 대조하고 출처별 AI 이름을 추정하지 않는다.
- 사용자가 넣어 달라고 하면 요청 위치까지 반영하되 단순 요약 요청으로 원문 삭제하지 않는다. 교체를 명시한 범위만 교체한다. 참고 교재 요약은 녹음 회차와 구분한 별도 제목·출처로 추가한다.
- 문서 편집은 실제 형식에 맞는 기존 스킬을 사용하고, 최신 위치·버전을 읽은 뒤 수정한다. 저장 후 다시 읽어 내용 일치와 개인 필기·대상 밖 회차 보존을 확인한다.
- 다른 공부 채팅 전달이 승인된 경우 study-coordination을 필요한 때만 사용한다. 보고된 검증 범위를 과장하지 않는다.
- 개인용 설정의 스킬 자동 개선 권한은 해당 사용자·채팅에 한정한다. 이 배포물 자체로 자동 개선·삭제·공유 권한을 만들지 않는다.

## 부분 확인의 한계

연결된 문서·대본의 실제 접근 범위를 먼저 확인한다. 개인 필기는 원문 그대로 보존하면서 중요한 주제를 대조하는 기준으로 사용한다. 대본 요약과 원음 확인을 구분하며, 회차별 출처가 없는 AI 요약의 시험 강조를 교수의 직접 강조로 확정하지 않는다.
