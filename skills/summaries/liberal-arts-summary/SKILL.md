# 교양 과목별 요약

[출처 원칙](../../sources/read-and-summarize/references/source-rules.md)을 따른다. 교수의 자료·학생의 필기·확인된 강조와 AI 보충을 구분한다. 시험 형식·범위·날짜는 현재 제공된 정보에서 확인하고 사용자 추측을 공지로 확정하지 않는다.

- 서양 현대사: 원인·과정·결과, 시대 간 연결과 같은 시기 다른 지역의 흐름을 근거에 맞춰 정리한다. 병행 사건을 억지로 인과로 묶지 않는다. 녹음 편집에는 `lecture-recording-summary`를 선택한다.
- 생명체 속 화학: 필기 핵심어·정의·분류·구조·기능·차이·반응 조건을 중심으로 한다. 그림·화학식·모형을 텍스트만으로 추측하지 않는다. 문서 정리에는 `life-chemistry-summary`를 선택한다.
- 미학: 실제 과제 문항과 수업 설명을 확인하고 개념·주장·논거·사상가 비교를 정리한다. 자료에 없는 사상가나 문항을 만들지 않는다.
- 중국 근현대사: 강별 개념·인물·사건·시기·구별점을 찾기 쉽게 정리한다. 연대와 인과는 이해에 필요한 항목에 붙인다.

모든 과목에 역사 흐름 형식이나 고정 표를 강요하지 않는다. 요청 회차의 필요한 항목만 선택하고 없는 내용을 채우지 않는다. 요약 요청에 문제·정답·학습 완료 판정을 자동 추가하지 않는다. 컴퓨터 시험이라는 사실만으로 외부 도움 허용을 가정하지 않는다.

반복 조회에는 `study-cache`를 필요한 때만 사용한다. 의미 있는 개선을 저장했을 때 변경과 확인 범위만 보고한다. 개인 시험 정보·문서 위치·삭제 권한은 이 배포물에 저장하지 않는다.

## 유형·시각 자료의 확인

실제 시험 후기와 강의 공지, 연습용 유형을 구분하고 다음 시험 형식의 보장으로 확대하지 않는다. 화학식·구조·모형은 원본 시각 자료에서 확인한 범위만 설명한다. 텍스트 추출로 그림을 보았다고 표시하지 않는다.
