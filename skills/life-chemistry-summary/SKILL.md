# 생명체 속 화학 강의 정리

[출처 원칙](../read-and-summarize/references/source-rules.md)을 따른다. 현재 사용자가 지정한 문서·필기·AI 요약·전사·출력 위치를 확인한다. 특정 문서나 채팅의 권한을 이 스킬이 대신 부여하지 않는다.

## 요약 판단

- 개인 필기의 밑줄·중요 용어와 교수 강조를 우선하고 AI 요약·전사와 대조한다. AI의 중요 표시만으로 출제를 확정하지 않는다.
- 정의·분류·구조와 기능·비교·반응식과 조건을 주제에 맞게 정리한다. 모든 내용을 역사식 흐름이나 화살표로 엮지 않는다.
- 영상 표현·화학식·모형이 시험 기준으로 확인되면 그 근거를 보존한다. 텍스트만 확보한 경우 모형의 시각 특징은 미확인으로 둔다.
- 회차 경계는 사용자 지정과 필기를 우선한다. 자료 번호가 다르면 대응을 기록하고, 충돌하는 용어·수치·반응식은 확인 필요로 남긴다.
- 전사 오류는 제공 자료에서 명확히 확인되는 경우만 수정한다. 구조와 기능, 분자 안과 분자 사이의 결합, 과정과 산물을 섞지 않는다. 외부 교재 추가는 요청 범위에 따른다.
- 시험 형식과 난이도는 현재 자료에서 확인한다. 요약 요청으로 연습문제를 만들지 않으며, 연습을 요청받으면 정답을 먼저 노출하지 않는다.

## 문서 반영

1. 현재 revision, 실제 탭과 요청 회차, 삽입 위치를 확인한다. 기존 문서 편집 도구를 사용한다.
2. 지정 구간에 요약을 추가하고 기존 회차와 개인 필기를 보존한다.
3. 다시 읽어 내용·위치·강조 반영과 대상 밖 구간 보존을 확인한다.
4. 사용한 원문 정리가 명시적으로 허용된 경우에만 검증한 해당 구간을 삭제한다. 미사용 자료·다른 회차·탭 구조는 유지한다. 이 배포물에 사전 삭제 승인은 없다.
5. 쓰기·삭제에 revision 제어를 사용한다. 동시 변경이 있으면 현재 범위를 다시 계산하고 실패한 요청을 그대로 반복하지 않는다.

실제로 드러난 누락·오진·중복만 좁게 개선한다. 저장한 변경과 이번 요약의 판단, 문서 검증과 학습 완료를 구분한다. 반복 조회에는 필요한 출처 구간만 재사용한다.

## 시험 안내 갱신과 모형 확인

최신 사용자 공지로 시험 유형을 확인하고 예전 예상과 구분한다. 이름·화학식·모형·특징을 연결할 때 모형의 시각적 특징은 실제 원본을 확인한다. 확인되지 않은 그림이나 영상 속 표현을 일반 지식으로 복원하지 않는다. 자료 간 용어·반응식 충돌은 확인 필요로 남긴다.
