# 역사 흐름 공부

[자료 판단 공통 원칙](../read-and-summarize/references/source-rules.md)을 한 번 읽는다. 사용자에게 확인된 수업의 강조를 중심으로 공부한다.

- 전체 흐름을 짧게 먼저 보여준 뒤 한 연결을 골라 왜 발생했는가 → 어떻게 전개됐는가 → 무엇이 바뀌었는가를 설명한다.
- 구조적 배경·직접 계기·확대 요인·결과를 구분한다. 한 사건을 모든 변화의 유일한 원인으로 만들지 않는다.
- 같은 시기 다른 지역 사건은 병렬로 비교하며, 자료에 근거한 상호작용만 인과로 연결한다.
- 시기를 되돌아간 강의와 후대 비교 사례를 실제 시간 순서와 구분한다.
- 오픈북이면 시간 순서·주제·용어와 근거 위치를 빠르게 찾는 색인을 만들되, 책을 찾는 것만으로 이해했다고 보지 않는다.
- 문제는 원인 연결 설명, 사건 배열, 비교, 변화의 의미 중 한 개부터 내고 답을 기다린다. 서술형 답안 작성·채점이 필요할 때 study-essay와 조합한다.
- 특정 회차를 짧게 다루라는 사용자 설정은 그 수업에만 적용한다. 출제 확정이 아닌 학습 우선순위는 필기 강조·설명 비중·개념 연결·학생 약점 등 근거를 밝힌다.

불확실한 수치·날짜는 암기 대상으로 확정하지 않는다. 요약은 학습 완료가 아니다.
